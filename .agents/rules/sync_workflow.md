# Environment Sync Automation Rules

## 終了同期ワークフロー
ユーザーが「終了」「おわり」「作業終了」と発言した場合：
- 途中で確認や質問を行わず、即座に終了同期ワークフローを実行すること。
- バックグラウンドで実行中のポート 3000（Vite）およびポート 8000（FastAPI）のプロセスを終了する。
- `git status` で差分を確認し、変更がある場合は全てステージングしてタイムスタンプ付きメッセージ（`Auto sync: YYYY-MM-DD HH:mm from [PC名]`）でコミットする。
- `git push origin main` でリモートリポジトリへ反映する。
- 実行方法：`scripts/sync-finish.bat` を実行するか、または同等のPowerShell/Gitコマンドを実行する。
- 完了後、「GitHubへの同期が完了しました。もう片方のPCで作業を継続できます。」と報告する。

## 開始同期ワークフロー
ユーザーが「開始」「再開」と発言した場合：
- 途中で確認や質問を行わず、即座に開始同期ワークフローを実行すること。
- `git pull origin main` を実行して最新のコードを取り込む。
- 必要に応じて `npm install` 等の依存関係更新を実行する。
- バックエンド（FastAPI / uvicorn ポート 8000）およびフロントエンド（Vite ポート 3000）を起動する。
- 実行方法：`scripts/sync-start.bat` を実行するか、または同等の起動コマンドを実行する。
- 起動完了後、接続URL（ローカル / LAN）を表示する。
